社团管理系统需求设计文档
====================================

一、用户角色与权限
------------------------------------
角色              权限概述
--------------------------------------------------------------
系统管理员        全局最高权限，管理所有社团和用户
社长(社团负责人)  管理自己社团的一切事务
社团干事          协助社长管理，有部分管理权限
普通成员          参加活动、查看社团信息
游客              仅可浏览公开的社团列表和基本信息


二、功能模块详细设计
------------------------------------

模块一：用户管理
------------------------------------
功能点            说明
--------------------------------------------------------------
注册 / 登录       学号+密码登录，支持找回密码
个人信息维护      修改头像、手机号、邮箱、简介等
我的社团          查看自己加入的所有社团及角色
入团申请记录      查看历史申请状态


模块二：社团管理（核心模块）
------------------------------------
功能点            说明
--------------------------------------------------------------
创建社团          提交社团名称、类型、宗旨、Logo，需管理员审核通过
注销/解散社团     社长发起 -> 管理员审核 -> 归档处理（成员已不足或名存实亡的社团）
社团信息编辑      修改社团简介、联系方式、纳新状态等
社团列表 & 搜索   按类型、关键词、学院筛选社团
社团详情页        展示简介、成员数、活动数、荣誉等
社团类型管理      管理员可增删社团类别（如：学术类/文艺类/体育类/公益类）


模块三：成员管理
------------------------------------
功能点            说明
--------------------------------------------------------------
加入社团          成员提交申请，社长/干事审批
退出社团          成员主动退出
移除成员          社长可移除违规成员
角色任命          社长可将普通成员提升为干事，或撤销干事身份
职务设置          社长、副社长、财务干事、宣传干事等
成员花名册        展示所有成员及职务、加入时间


模块四：活动管理
------------------------------------
功能点            说明
--------------------------------------------------------------
发布活动          填写活动名称、时间、地点、人数上限、活动介绍
活动报名          成员报名参加活动
活动签到/签退     现场扫码或手动签到，记录出勤
活动取消          活动取消并通知已报名成员
活动总结          上传活动照片、撰写活动总结
活动日历          以日历视图展示当月所有社团活动
历史活动          归档查看往期活动


模块五：财务管理
------------------------------------
功能点            说明
--------------------------------------------------------------
会费缴纳          成员缴纳会费，记录缴费状态
经费收支记录      每一笔收入/支出有明细（金额、用途、经手人、时间）
余额查看          社团当前经费余额
经费申请          社团向学校申请活动经费
财务报表          按学期/学年生成收支汇总报表


模块六：通知公告
------------------------------------
功能点            说明
--------------------------------------------------------------
社团公告发布      社长/干事发布社团内部公告
系统通知          管理员发布全局通知
消息提醒          审批结果、活动提醒、缴费提醒等
公告列表          按时间查看所有公告


模块七：物资与场地管理
------------------------------------
功能点            说明
--------------------------------------------------------------
物资入库/出库     记录社团物资的借用和归还
物资库存          查看当前可用的物资及数量
场地申请          线上申请教室/场地，管理员审批


三、数据库核心表设计
------------------------------------
表名                    主要字段
--------------------------------------------------------------
Users                   UserId, StudentId, Name, Password, Phone, Email, Avatar, Role, CreatedAt
Clubs                   ClubId, Name, CategoryId, Logo, Description, FounderId, Status(待审核/正常/已注销), CreatedAt
ClubMembers             Id, ClubId, UserId, Role(社长/干事/成员), Position, JoinedAt
JoinApplications        Id, ClubId, UserId, Status(待审批/通过/拒绝), ApplyTime
Activities              Id, ClubId, Title, StartTime, EndTime, Location, MaxPeople, Status, CreatedAt
ActivityRegistrations   Id, ActivityId, UserId, SignInTime, SignedIn(是否签到)
FinanceRecords          Id, ClubId, Type(收入/支出), Amount, Description, Handler, RecordTime
Notices                 Id, ClubId(null=全局), Title, Content, PublisherId, PublishTime
Categories              Id, Name, Description
Assets                  Id, ClubId, Name, Quantity, Available
AssetBorrowings         Id, AssetId, UserId, Quantity, BorrowTime, ReturnTime, Status
VenueApplications       Id, ClubId, Venue, Purpose, StartTime, EndTime, Status


四、技术栈
------------------------------------
层       技术
--------------------------------------------------------------
前端     WinForms / WPF（桌面应用）
后端     C#, .NET Framework / .NET Core
数据库   SQL Server (SQL Server Management Studio 22)
ORM      ADO.NET 或 Entity Framework
报表     RDLC 或第三方报表控件


五、开发优先级建议
------------------------------------
优先级       模块内容
--------------------------------------------------------------
第一优先级   用户管理 + 社团管理（增删改查）+ 成员加入/退出
第二优先级   活动管理（发布、报名、签到）
第三优先级   财务管理 + 通知公告
第四优先级   物资场地 + 报表统计 + 美观优化

 现在有个问题当这个社团剩下最后一个成员的时候，我没办法删除这个成员。那就这样实现:社长不能自己删除自己(退出社团)，只
  能管理员这么做。但是社长可以将自己的社长职位给其他社团成员，这个时候，社长就变成了普通成员。对于一个社团的最后一个人
  (一般来讲都是社长)，这个时候只能管理员删除(废除)这个社团，如果管理员，直接删除了社团最后一个人，这是提示是否直接删除
  此社团，是的话，就直接删除，不是的话，提示不能删除社团的最后一人。

六、项目模块划分
====================================

本项目按功能性质分为两大板块：

第一大板块：通用功能（面向所有用户，包括游客）
------------------------------------

  1. 用户认证模块
     - 登录 / 注册 / 退出
     - 角色身份标签显示

  2. 社团浏览模块
     - 社团列表展示（卡片视图）
     - 社团搜索与分类筛选
     - 社团详情查看（简介、照片、附件下载预览）

  3. 活动广场模块
     - 所有活动浏览
     - 活动详情查看（简介、照片轮播、附件下载）
     - 活动报名（需校验时间与名额）
     - 报名审批（社长/干事/管理员）
     - 我的报名记录查看

  4. 我的社团模块
     - 查看已加入社团及角色
     - 查看入团申请记录与状态
     - 退出社团（非社长）

  5. 通知公告浏览模块
     - 控制台最新公告展示（按权限过滤）
     - 公告详情查看（内容、照片、附件下载预览）

  6. 控制台首页模块
     - 统计数据卡片（社团总数、成员总数、活动总数、通知数）
     - 最近社团与最新公告快速入口


第二大板块：管理功能（仅管理员、社长、干事可见可操作）
------------------------------------

  1. 社团管理模块
     - 创建社团（自动成为社长）
     - 删除社团（仅管理员）
     - 社团信息编辑（仅管辖者）
     - 社团详情管理（上传照片/附件）
     - 社团信息修改提交审核（社长/干事 -> 管理员审批）

  2. 成员管理模块
     - 社团成员列表查看
     - 入团申请审批（通过/拒绝）
     - 设社长（管理员/社长可转让）
     - 提升干事 / 降为成员
     - 移除成员（含最后一人保护逻辑 + 管理员强删社团）

  3. 活动管理模块
     - 发布活动（名称、时间、地点、人数上限、简介）
     - 编辑活动信息（名称、时间、地点、简介）
     - 活动详情管理（上传/删除照片和附件）
     - 取消活动

  4. 财务管理模块
     - 收支记录查看
     - 新增收支记录（收入/支出、金额、用途）
     - 删除收支记录
     - 当前余额显示

  5. 通知公告管理模块
     - 发布公告（全局或指定社团）
     - 公告详情管理（编辑标题/内容、上传/删除照片和附件）
     - 删除公告

  6. 场地申请模块
     - 申请场地（名称、用途、起止时间）
     - 场地申请审批（管理员通过/拒绝）
     - 场地申请记录查看
